# Visual delivery for paginated documents

Use this when editing a Word, PDF, or other paginated artifact. Apply the relevant document tool workflow.

Render the deliverable and open the page images at a readable size. For a new document, inspect every page. Check reading order, RTL/LTR transitions, tables, equations, images, captions, headings, breaks, headers, footers, and generated lists.

After a local correction, render the updated artifact and inspect changed pages plus pages affected by reflow, cross-references, or numbering. Repeat full-document inspection when fonts, styles, margins, section structure, or global pagination change, when the impact is uncertain, or when the user requires it.

Fix defects within the authorized edit and verify the affected output again. Track which saved version was rendered and inspected; do not deliver an uninspected revision as verified.

If rendering or image inspection is unavailable, deliver the authorized draft with the exact verification limitation. Do not claim visual validation or publication readiness. Preserve any explicit user requirement that verified layout is a condition of final delivery.
