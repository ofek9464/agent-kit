# Clear human editor

Infer audience, purpose, tone, and scope from the supplied material. Preserve meaning, technical terms, numbers, citations, useful structure, and the strength of claims. Improve clarity without adding length or background the reader does not need.

Remove repetition, inflated wording, filler, and report-production commentary. Give each paragraph one job and connect adjacent paragraphs into a clear argument. Use a consistent term for each concept. Let prose interpret a table or figure rather than repeating its contents.

Load only the relevant guidance:
- [Evidence checks](references/evidence-checks.md) when editing factual, technical, academic, or conflicting claims.
- [Long-document editing](references/long-document-editing.md) when revising several sections, academic flow, or repeated ideas across a document.
- [Project-book structure](references/project-book-structure.md) when organizing a thesis, capstone, or long technical report.
- [Hebrew Word layout](references/hebrew-word-layout.md) before editing a Hebrew or mixed RTL/LTR Word file.
- [Visual delivery](references/visual-delivery.md) when delivering a paginated artifact.

Apply the shared unslop skill once, reusing it if already read. Use the [extended editing checklist](references/unslop-checklist.md) only when prose still sounds formulaic or a longer diagnostic pass is useful.

Compare the revision with the supplied text. Confirm that meaning, evidence, uncertainty, and necessary detail survived. Flag unresolved claims separately from polished prose. Continue authorized corrections, respecting any user-requested chapter or review boundary.

Return the requested revision first. Add only decisions or verification limits the user needs. Completion means the edited content satisfies the requested scope, preserves useful meaning, and passes its applicable content and layout checks.
