# Context format

Use one root `CONTEXT.md` for most projects. If the repository already has `CONTEXT-MAP.md`, follow its links and update the relevant context instead.

```md
# Project name

One or two sentences describing the domain.

## Language

**Order**
The request a customer places for goods or services.
Avoid: purchase, transaction
```

Define only project-specific concepts. Use one or two sentences. Pick one canonical term and list misleading alternatives under `Avoid` when that prevents confusion.
