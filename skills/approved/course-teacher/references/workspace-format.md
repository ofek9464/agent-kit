# Course workspace

Use these files only when the course needs them:

```text
MISSION.md              Why the user wants to learn the topic and what success means
RESOURCES.md            Trusted books, documentation, papers, courses, and communities
NOTES.md                Temporary teaching preferences and working notes
lessons/                Numbered lesson files
reference/              Concise material worth revisiting
learning-records/       Numbered records of durable progress and misconceptions
```

Keep each lesson focused on one observable goal. A learning record should state what the user can now do, the evidence, what remains difficult, and the best next lesson.
