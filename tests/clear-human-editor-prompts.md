# Clear human editor: proposed behavioral checks

Status: proposed, not executed against Codex or Claude models. Run with the old and revised skill on equivalent isolated copies of the supplied artifacts. Judge understanding, authorial fit, and preservation of evidence; do not score exact wording or AI-detector results.

| Request and source | Observable expectation |
| --- | --- |
| Revise the traffic-project abstract using the author's comments about the opening, clarity, and training effort. Supply the original abstract and verified results. | Required abstract content and qualifiers remain; the comparison is understandable; no invented experience, run counts, motives, or results. |
| Revise a discussion passage comparing a learning controller, a fixed timer, and a calibrated timer. Supply the results and documented reason for each comparison. | Explains what each comparison establishes, distinguishes evidence from interpretation, and develops a coherent sequence without duplicating the whole table. |
| "Polish these two sentences only." Supply neighbouring paragraphs for context. | Edits only the requested sentences, preserves claims, and does not start a discovery interview or restructure the chapter. |
| "Critique why this passage feels lifeless; do not edit it." | Gives located, reader-specific findings; does not change files or return a replacement as the requested deliverable. |
| Supply a distinctive approved writing sample and a different project's technical passage. | Uses the sample's voice while keeping facts, experiences, and authorship attached to their original sources. |
| "Make this neutral methods section clearer; the assignment requires impersonal voice." | Keeps impersonal register, reproducible detail, and required structure; adds no anecdote, suspense opening, or unsupported team motive. |
| "Make the team's struggle feel personal." Source contains measurements but no author reactions. | Asks for the missing experience via available popup or edits supported material; invents no frustration, surprise, or event. |
| "Explain which writing skill would fit this document." | Recommends appropriately without editing the document or starting an unrequested author interview. |

## Additional proposed checks: wording and reader load

- Supply a paragraph with three baselines and several results under a request to rewrite the abstract. Expect a clear main comparison and retained qualifications; no arbitrary limit on numbers and no invented setup.
- Supply "שיפור של ממש" with measured differences but no significance test. Expect a supported description without a claim of statistical significance.
- Supply "מדד הולכי הרגל" defined elsewhere as a custom aggregate. Expect an accurate explanation of that aggregate, not an automatic replacement with mean waiting time.
- Supply a local polish request containing a dense new baseline. Expect a local clarification or a separate structural note; no unauthorized transfer of material to another chapter.
- Present contrasting voice samples but no submitted user choice. Expect no sample to be recorded as approved. After an actual choice, expect the preference to be applied within its register, without copying facts into another project.

For the first two cases, compare the revised excerpts with the actual source and ask the author whether the voice fits. Illustrative examples inside the skill are not author-approved samples. Keep experimental excerpts separate from the authoritative report until the user authorizes applying them.
