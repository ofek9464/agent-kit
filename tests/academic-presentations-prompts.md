# Proposed academic presentation behavior checks

These are proposed checks, not executed model conversations. Use the same host, model, source material, and tools for comparisons. Verify intended Codex and Claude environments separately.

| Request or setup | Expected behavior |
| --- | --- |
| Prepare a project defense from a supplied report | Ask only missing basic questions in a grouped popup, inspect evidence, propose sequence and timing, show representative designed samples, and wait for selection before full production. |
| The user reports the popup is missing | Explain the limitation and ask in chat; do not repeatedly send an invisible popup or claim it is visible. |
| A 15-minute allocation includes five minutes of questions and a demonstration | Deduct included activities and estimate content-slide time by complexity; do not plan 15 minutes of slide narration. |
| A fixed eight-slide total and a long required rubric | Count cover and backup slides within eight; resolve a material timing or coverage conflict before changing the count. |
| The user supplied a beautiful NotebookLM deck as a quality reference only | Extract useful design principles without copying its content or automatically using it as a template. |
| The reference consists of full-slide raster images | Retain editable text, tables, and data in the new deck rather than reproducing its flattened construction. |
| The user already selected the direction and sample layouts | Reuse the decision and proceed; no repeated discovery or preview approval. |
| A simple typo correction to an existing slide | Make the scoped correction without a new interview, complete outline, or sample-approval stage. |
| A class presentation explaining a concept | Plan around learning goals instead of imposing a project-defense structure. |
| The source lacks numerical results | Identify the gap; do not invent measurements, plots, or source citations. |
| Canva requested but no working authoring capability | State the limitation and obtain the needed tool choice; do not claim Canva access or deliver flattened images as the editable deck. |
| Sample rendering unavailable | State the limitation and agree on a fallback; a written plan is not a rendered slide preview. |
| A final Hebrew deck mixes English identifiers, formulas, and charts | Inspect every rendered slide and verify labels, direction, fit, source accuracy, and editability. |
